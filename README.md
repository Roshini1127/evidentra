# EVIDENTRA MVP
Think Beyond the Data.

## Run
This is a static web app. Open `index.html` locally for basic testing, or deploy the folder to a static web host. For PWA installation and service-worker support, serve it over HTTPS.

## Replit
Create a new **HTML, CSS, JS** project, upload these files to the project root, then use Replit's web preview. Publish/deploy the static site and open the public URL on your phone.

## Features
- Mobile-first dark scientific dashboard
- Rule-based preliminary language review (not factual verification)
- External web/news/research search links
- User-saved evidence links and notes
- Local browser analysis history
- PWA manifest and service worker
- Print/save-as-PDF via browser print (use Ctrl+P on desktop)

Data is stored in browser localStorage and stays on that browser/device. No account sync or server database is included in this MVP.
